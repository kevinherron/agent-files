# Diataxis Documentation Templates

Use these as reusable skeletons, not mandatory formats. Adapt headings to local documentation conventions and remove placeholder text before delivering.

## Tutorial Skeleton

```markdown
# Build your first <thing>

In this tutorial, you will create <concrete outcome>.

## Before you start

You need <minimal prerequisites>.

## Create <first piece>

Do <step>.

You should see <expected result>.

Notice <small observation>.

## Continue

Do <next step>.

You should see <expected result>.

## Check your result

You have <completed outcome>.
```

## How-To Skeleton

```markdown
# How to <achieve specific goal>

Use this guide when <real-world situation>.

## Prerequisites

You need <assumed setup or competence>.

## Steps

1. <Action>.
2. <Action>.
3. If <condition>, <action>; otherwise, <action>.

## Verify the result

<Check or expected state>.

For full options, see <reference link>.
```

## Behavior

## Errors

<Codes and meanings>.

<Concise illustrative examples>.
```

## Explanation Skeleton

<Background>.

- Trying to <goal>? Use <how-to link>.

- Need background? Read <explanation link>.

- <Task link>
- <Task link>

```

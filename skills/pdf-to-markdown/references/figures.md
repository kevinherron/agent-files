# Optional figure images

Read this only when the requested corpus should include original diagrams alongside
their text transcriptions. Resolve script paths from the skill directory.

**5. Figures (optional — extract & link diagram images).** The convert phase renders every diagram/figure faithfully **as text** (step lists, field tables); this phase *additionally* attaches the original figure as a cropped image, so a fragment keeps both the machine-readable transcription and a visual reference. Only worth it when figures carry meaning a reader will want to *see* (wiring/topology, state machines, sequence/stack diagrams) and the PDFs are born-digital. Steps: (a) `python3 scripts/extract_figures.py <root>` crops each `Figure N` to `<doc>/figures/figure-NN.png` and writes `_maps/figures.json`; (b) **verify-and-prune** — use direct image inspection or available authorized agents to *view* each PNG and flag bad crops (table/body-text mashed in, cut-off figure, sidebar box, or an in-text reference mistaken for a caption), list the bad image paths in `_maps/figures_deny.json`, and re-run extract (the denylist is honoured); (c) `python3 scripts/inject_figures.py <root>` injects the surviving images beneath each `Figure N` heading. The extractor is heuristic: it nails clean single-column pages but a *densely packed* page (tables abutting the diagram with no whitespace gap) may over- or under-crop — that is what the verify-and-prune catches. Pruned figures simply stay text-only; never attach a wrong/cut image. `pdfimages` is **not** the tool here — these figures are vector drawings with no embedded raster, so they must be *rendered*, which `extract_figures.py` does. Deps: `pymupdf`, `pillow`, `numpy`.
